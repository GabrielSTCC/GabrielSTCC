# Gabriel Santos Teixeira

Desenvolvedor full stack. Construo produtos web, APIs e sistemas que resolvem fila, atendimento, rotas e decisão — do painel que o time usa no dia a dia ao algoritmo por trás da escolha.

**English.** Full stack developer focused on web products, REST APIs, and applied optimization and AI. Public work includes a real-time queue SaaS, a Java support-ticket system, and academic projects on search, game-playing agents, and route optimization.

## Projetos

### [Waitless](https://github.com/GabrielSTCC/Waitless)

SaaS de fila de espera com painel Kanban em tempo real, mini-CRM e link público para o cliente acompanhar posição e tempo estimado, sem login.

Stack: Next.js, React, TypeScript, Firebase, Tailwind.  
Demo: [waitless.solutions](https://www.waitless.solutions)

### [Arena Bot](https://github.com/GabrielSTCC/arena-bot-pp01)

Dois agentes competem por minérios numa grade, escolhendo rota e alvo com busca e jogo adversarial. Projeto prático de Inteligência Artificial da UFC Russas.

Stack: Python, A*, Minimax com poda alfa-beta, base de conhecimento proposicional.

### [Caixeiro viajante com GRASP](https://github.com/GabrielSTCC/problema-caixeiro-viajante-grasp)

Ordem de entrega que reduz a distância total em um caso real em Russas-CE, com distâncias de estrada e interface com mapa.

Stack: Python, GRASP, busca local 2-opt, Streamlit.

### [Sistema de chamado](https://github.com/GabrielSTCC/Sistema-De-Chamado)

Abertura, acompanhamento e encerramento de chamados, com permissões diferentes para usuário e administrador.

Stack: Java, Swing, PostgreSQL, Maven, MVC.
